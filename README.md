## KURULUM (Chrome / Edge / Brave)
1. Bu klasörü bir yere çıkarın (zip ise açın).
2. chrome://extensions adresini açın, sağ üstten "Geliştirici modu"nu açın.
3. "Paketlenmemiş öğe yükle" deyip klasörü seçin.
4. Cinema8 videosu olan sayfayı yenileyin. Video varsa sol üstte küçük bir panel çıkar.

## KISAYOLLAR
Videonun sol üst kısmında küçük bir yönetim paneli açılıyor otomatik olarak illa kısayol kullanmak zorunda değilsiniz.
Alt + ↑ / ↓  : hızı 0.25 artır / azalt
Alt + 0      : 1x'e dön
Alt + S      : ekran görüntüsü (PNG, videonun orijinal çözünürlüğünde)

## NOT
- Chrome'da oynatma hızı pratikte 16x'e kadar düzgün çalışır; üstünde ses/görüntü bozulabilir.
- Sadece belirli siteler için çalışmasını isterseniz manifest.json'daki "matches" alanını daraltın.
- DRM'li (EME) videolarda ekran görüntüsü siyah çıkabilir.
